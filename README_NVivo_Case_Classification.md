## 📋 About This Report

This repository contains an intern training report on **case classification in NVivo** — the method used to assign demographic attributes (such as gender, age, role, or location) to specific participants or subjects in a research study.

By creating **classification sheets**, researchers can organize project data to effectively **compare different subgroups** — for example, analyzing how different age groups or genders perceive a topic such as environmental change.

The report is prepared from an instructional video transcript demonstrating the complete setup procedure.

## 🧭 Quick Reference: The 5 Setup Steps

| Step | Action |
|------|--------|
| **1. Navigate** | Go to the **Cases** group in the Navigation Pane → expand → select **Case Classifications** folder. |
| **2. Create** | Right-click in the working area → **New Classification** → name your sheet (e.g., *Participant Demographics Sheet*). |
| **3. Add attributes** | Right-click in the new table → **New Attribute** → define categories like *Gender*, *Age*, *Location*. |
| **4. Define values** | Under the **Values** tab → keep defaults (*Unassigned*, *Not Applicable*) → click **Add** → enter custom values (e.g., *Male*, *Female*). |
| **5. Consolidate** | Use **Cut and Paste** to move existing attributes from other tables into your new sheet. |
